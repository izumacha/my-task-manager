# ruff / mypy は上限を切って固定する。
# どちらも「新しい版で検査が厳しくなる」種類のツールで、上限なしにすると CI は毎回
# 最新版を取りに行くため、コードを 1 行も触っていない PR が、上流のルール追加だけで
# 突然赤くなる（＝失敗の原因が差分の中に無い状態になる）。
# 上限を切っておけば、追随のタイミングを Dependabot の PR として受け取れるので、
# 「無関係な PR が突然赤くなる」代わりに「その PR の中で新ルールに対処する」形になる
# （§9「依存を管理する」）。
# 注: ruff 0.14 → 0.15 は Dependabot の分類上 minor なので、.github/dependabot.yml の
#     pip-minor-and-patch グループに束ねられて届く（単独 PR にはならない）。
# ruff は 1.0 未満で、マイナー更新（0.14 → 0.15）に選択カテゴリへの新ルール追加が入るため
# マイナー単位で、mypy は semver に従うためメジャー単位で上限を置く。

mypy>=2.3.1,<3.0.0
